My Projects


Here are some descriptions of projects that I've done. The first project is what led me to love analyzing neural networks and taking inspiration from the brain. While most of my projects are on Github, the others are projects are ones that I unfortunately could not, but were very fun and satisfying nonetheless.


  • Neural Network Behavior Exploration: This project got me super interested in neural network behavior and sent me down the rabbit hole — experiments on sparse vs dense CNNs.
  • AI-Powered Solution Agent: Built a production-ready AI tutoring assistant using LangChain, LangGraph, and RAG pipelines to retrieve knowledge from instructor notes and generate personalized responses for students, achieving scalable support with significantly reduced inference costs through GPT-4o Mini.


  • Inverted Pendulum on a Cart: Created a model of an inverted pendulum on a cart in python. Analyzed the system dynamics to linearize and control the system using the linear quadratic regulator (LQR). Achieved a stable system that works on arbitrary eigenvalues (poles).

  • New York Taxi Fares Prediction: Using Apache Spark, created a big data application to analyze New York Taxi fares dataset on Kaggle and perform machine learning analysis on it, using a cluster computing network initialized in Amazon EC2 instances. Using a regression model, and specific features extracted, taxi prices were predicted with an R2 score of 0.96.
